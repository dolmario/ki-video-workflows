# Local AI business checklist

1. Choose a concrete task and verifiable knowledge sources.
2. Define permitted sources/folders and a separate test user; a prompt is not actual access control.
3. Record source versions, material read and answers; use only this synthetic exercise data.
4. Test deliberately unknown facts and an outdated source; an unsupported answer is not evidence.
5. Assign maintenance, version changes and repeated tests.

This template is not business deployment approval. Do not add customer data, passwords or private documents.
